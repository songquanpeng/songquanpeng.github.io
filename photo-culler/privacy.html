This privacy policy describes Photo Culler for macOS, developed by Quanpeng Song.

No developer data collection

The app does not send photos, ratings, file paths, photo metadata or usage analytics to the developer. It has no account, advertising, tracking SDK, analytics service or developer-operated server.

Local files and permissions

You choose which source and library folders the app may access through macOS folder pickers. The app reads JPG/RAW files and photo metadata to pair files, group by capture date and build previews. Security-scoped bookmarks retain access to selected folders. Ratings, folder records and resumable import tasks are saved in the app's local Application Support directory. Previews and thumbnails use the system Caches directory.

Sharing and importing

Import copies the selected original file types to a library you choose. Sharing starts only after you select files and a system sharing service. Original files can include camera metadata or location information already present in the files. Your selected sharing service handles delivery under its own privacy policy; the developer does not receive a copy.

Retention and deletion

Ratings and cached previews can remain available after disconnecting a card. Removing a sidebar entry hides it while retaining its catalog records, ratings and previews for later reuse. Cache & Settings lets you clear previews without deleting ratings or originals. File deletion requires confirmation and uses the system Trash; if recoverable deletion fails, the app reports the failure instead of permanently deleting the file.

Local catalog backups contain folder records and ratings, so keep them private. To remove all app-held data, quit the app and remove its local application data through Finder; contact support for help locating it. Original photos and exported backups remain where you saved them. No developer account or server-side photo data exists to delete.

Support and this website

If you choose to submit a support issue, GitHub receives the information you provide. Issues are public, so avoid private photos and personal information. This website is hosted by GitHub Pages, which may process standard request information under GitHub's privacy policy. The app does not embed this website or use it for tracking.

Contact and changes

For privacy questions, use the support page. Material changes will be reflected here with an updated effective date.

你的照片
留在你的 Mac。

本隐私政策适用于 Quanpeng Song 开发的 macOS 应用“挑图”（Photo Culler）。

开发者不收集应用数据

应用不会向开发者发送照片、星级、文件路径、照片元数据或使用统计。没有账户、广告、跟踪 SDK、分析服务或开发者运营的服务器。

本地文件与权限

你通过 macOS 文件夹选择器决定应用可以访问的来源和图库。应用读取 JPG/RAW 文件及照片元数据，用于配对、按拍摄日期分组和生成预览。安全书签用于保留对所选目录的访问。星级、目录记录和可恢复的导入任务保存在本地 Application Support 目录；预览和缩略图保存在系统 Caches 目录。

分享与导入

导入将所选类型的原件复制到你指定的图库。分享仅在你选择文件和系统分享服务后开始。原件可能包含文件中已有的相机元数据或位置信息。所选分享服务依据自身隐私政策处理传输，开发者不会收到副本。

保留与删除

拔卡后星级和已有预览仍可使用。移除侧栏入口只隐藏目录，会保留索引、评分和预览，以便重新接入。“缓存与设置”允许清理预览，保留星级和原件。删除文件需要确认并使用系统废纸篓；可恢复删除失败时会报告错误，不会改为永久删除。

图库备份包含目录记录和评分，请妥善保管。若要清除应用保存的全部本地数据，请退出应用后通过 Finder 删除其本地应用数据；可联系支持获取定位方法。原始照片与导出的备份仍留在你保存的位置。应用没有需要注销的开发者账户或需要远程删除的服务器照片数据。

支持与本网站

如主动提交支持反馈，GitHub 将接收你提供的信息。反馈公开，请勿附上私人照片和个人信息。本网站托管在 GitHub Pages，服务商可能按照 GitHub 隐私政策处理常规访问请求信息。应用不会内嵌本网站或利用它进行跟踪。

联系与更新

隐私问题可通过支持页面反馈。政策发生实质变化时，本页会更新生效日期。
